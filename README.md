# DermaCare — Dermatology App UI

**AppStorm project**  
**Author:** Лесбек Диас

A responsive dermatology / medical health dashboard concept. Built with plain HTML, CSS and JavaScript — no framework or build step required.

## Features
- Responsive dashboard layout for desktop, tablet and mobile
- Patient overview and upcoming appointment card
- Daily skincare routine with interactive checkboxes and progress
- Skin check-in with mood selection and notes
- Community story preview
- Toast notifications for demo interactions

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example, `dermacare-appstorm`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment. Your website link will appear in the Pages section.

## Important note
This is a front-end educational UI prototype. It does not provide diagnosis, store medical records, or connect to real doctors. The appointment, community and check-in content is sample/demo data and should not be used as medical advice.
